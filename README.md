# Hamass Nagieb — Story Portfolio

A lightweight GitHub Pages portfolio built as one continuous visual story.

## Visual concept
- Cream / dusty rose / warm brown luxury palette.
- One continuous animated atmosphere behind the entire site.
- Soft waves, silk lines, mist, light and tiny particles move slowly behind the content.
- Foreground content stays readable and changes as the visitor scrolls through the story.
- No large AI globe or orbit objects in the background.

## Sections
Home → About → Education → Skills → Experience → Services → Projects → Achievements → Contact

## Publish on GitHub Pages
1. Extract the ZIP.
2. Replace the files in your `hamassnagieb.github.io` repository.
3. Keep `index.html`, `style.css`, `script.js`, `.nojekyll`, and `assets/` in the repository root.
4. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Before publishing
Replace `your-email@example.com` in `index.html` with the real contact email. Replace placeholder project/experience text with the final verified portfolio content.

The animation is built with plain HTML/CSS/JS and includes a reduced-motion fallback.
